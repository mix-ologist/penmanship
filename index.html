Guide rules

Slant-line spacing is measured horizontally along the baseline.

The default rule has three equal 5 mm bands: ascender, letter body, and descender. X-height is the distance from the dashed line to the darker baseline. The row gap is extra blank space between complete rule sets.

Blank fields print as writing lines. Row count adjusts to fit the page.

Print at 100% / Actual size, turn off browser headers and footers, and match the selected paper size to keep the guides accurate.
